# Diagrammes UML

Sources PlantUML (outil libre) du projet Patrimoine Togo :

- `cas-utilisation.puml` : les quatre rôles et leurs fonctions
- `classes.puml` : biens, catégories, ministères, affectations, pannes, demandes, utilisateurs
- `sequence-validation.puml` : proposer un bien puis le faire valider

Pour obtenir les images : coller le contenu d'un fichier dans https://www.plantuml.com/plantuml ou ouvrir le fichier avec l'extension PlantUML de VS Code.
